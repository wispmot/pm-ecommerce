### 4.1. Модель данных (Entity)

**Таблица:** `products`

| Поле | Тип | Ограничения | Описание |
|------|-----|-------------|----------|
| `id` | Long | PK, AUTO_INCREMENT | Уникальный идентификатор |
| `name` | String | NOT NULL, max 200 | Название товара |
| `description` | String | max 1000 | Описание товара |
| `price` | BigDecimal | NOT NULL, min 0.01 | Цена товара |
| `stock_quantity` | Integer | NOT NULL, min 0 | Количество на складе |
| `created_at` | LocalDateTime | Auto-set | Дата создания |
| `updated_at` | LocalDateTime | Auto-update | Дата обновления |

**Подсказки:**
- Используй `@CreationTimestamp` и `@UpdateTimestamp`
- Для `price`: `precision = 10, scale = 2`

## 5. API ENDPOINTS

**Базовый URL:** `http://localhost:8080/api/v1/products`

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| GET | `/` | Список товаров (пагинация, фильтры) |
| GET | `/{id}` | Получить товар по ID |
| POST | `/` | Создать товар |
| PUT | `/{id}` | Полное обновление |
| PATCH | `/{id}` | Частичное обновление |
| DELETE | `/{id}` | Удалить товар |
| GET | `/in-stock` | Только товары в наличии |

**Параметры GET `/`:**
- `page` (0) — номер страницы
- `size` (10) — размер страницы
- `sort` (name,asc) — сортировка
- `name` — поиск по названию
- `minPrice` / `maxPrice` — фильтр по цене

**Пример ответа (GET /):**
{
"content": [
{
"id": 1,
"name": "Смартфон X100",
"price": 49999.99,
"stockQuantity": 25,
"createdAt": "2026-07-15T10:30:00",
"updatedAt": "2026-07-15T10:30:00"
}
],
"pageNumber": 0,
"pageSize": 10,
"totalElements": 42,
"totalPages": 5
}
