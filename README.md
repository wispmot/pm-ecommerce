# pm-ecommerce

## Описание проекта
Бэкенд-модуль для e-commerce приложения. Реализован на Java (Spring Boot) с использованием PostgreSQL в качестве базы данных и Liquibase для управления миграциями.

## Технологический стек
* **Java 21**
* **Spring Boot 3.5.16**
* **PostgreSQL 16**
* **Liquibase** (миграции БД)
* **Gradle** (сборщик проекта)
